# Rive work by Muhammad Ali Sabir

Live Rive files, playable in the browser: https://ranjoooo.github.io/rive-showcase/

| Piece | What it shows |
|---|---|
| [Juno](https://ranjoooo.github.io/rive-showcase/juno.html) | Lip-synced character: one mouth morphing through 12 visemes timed to a real voice line, moods, blink, pointer look, captions keyed word by word |
| [Firefly Jar](https://ranjoooo.github.io/rive-showcase/firefly.html) | Mini-game: Rive artboards as sprites, a Luau script running the round, data binding driving the HUD |
| [Pip](https://ranjoooo.github.io/rive-showcase/pip.html) | Character rig with a 16-layer state machine and a data-bound control panel |
| [Tank Gauge](https://ranjoooo.github.io/rive-showcase/tank.html) | Data-bound status component for a delivery app |

Runs on `@rive-app/webgl2`. The `.riv` files are signed builds.
